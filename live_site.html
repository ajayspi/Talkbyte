Expansion architecture
The backend is a plug-in system. Each market/vertical needs: a POS adapter (FastAPI router), a payment gateway swap (Stripe handles most), a language model for Deepgram, and a phone number pool via Telnyx. The AI pipeline — LiveKit → Deepgram → GPT-4.1 → ElevenLabs — is market-agnostic.

~1 week per new language
