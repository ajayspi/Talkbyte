Master Design Prompt
Copy this prompt when asking an AI agent to build a new TalkByte screen. It encodes all decisions above so every generated screen stays on-brand.
System / Design Context
You are building a screen for TalkByte — an AI phone ordering platform for Australian restaurants.

PRODUCT CONTEXT
Customers call a Telnyx number → LiveKit voice agent (Deepgram STT + GPT-4 + ElevenLabs TTS)
takes the order → FastAPI backend → Supabase DB → Square POS sync + Stripe billing.
Two portals: Restaurant Dashboard (ops staff) and Admin Panel (platform operators).

TECH STACK
Next.js 16, React 19, TypeScript, Tailwind v4, Supabase JS v2, TanStack Query v5, Zustand v5.
Use CSS custom properties from globals.css — no hardcoded hex values.

COLOR TOKENS
--violet: #7c3aed --teal: #14b8a6 --orange: #FF6B35
--bg: #0f172a --bg-card: #1e293b --sidebar: #1a0a1e
--green: #22c55e --yellow: #f59e0b --red: #ef4444

TYPOGRAPHY
Font: Inter (system-ui fallback). Mono: JetBrains Mono for IDs, timers, counters.
Heading weight: 700–800, tight letter-spacing. Body: 14px/400/1.6.

COMPONENT RULES
Cards: bg-card, border var(--border), radius 14px, padding 20px, box-shadow shadow-card.
KPI tiles: 2px colored top-border (violet/teal/orange/green), 32px font-weight-800 value.
Buttons: gradient primary (violet→purple), gradient secondary (teal), ghost for tertiary.
Badges: pill, transparent tinted bg, never solid fill. Dot prefix for live states.
Sidebar: 240px, bg-sidebar, active item = gradient + 3px teal left border.
Tables: uppercase 10px headers, subtle row hover, IDs in mono, badges in cells.

VOICE-FIRST PATTERNS
Live calls: pulsing green ring animation, mono timer, animated waveform bars.
Transcript: teal bubbles (AI) vs violet bubbles (caller), rounded chat style.
Status dots: animated blink for live/active, static for offline/inactive.

DARK MODE
App is dark-native. Light mode swaps surface tokens only — brand accents stay identical.
Never hardcode a color that would break in light mode. Always use a token.

TONE
Intelligent. Operational. Alive. Data-dense but never cluttered.
Think Vercel dashboard × Stripe × Retool — but for a kitchen environment.
